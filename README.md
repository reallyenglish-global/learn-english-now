# Learn English Now

Exploring the next generation of LEN with Flutter.

**Status: feasibility and discovery; not a released app.** This repository currently contains planning documents, not an executable Flutter application. Flutter is a candidate, not an approved replacement for React Native.

## Goal

Evaluate a shared learning experience across Android, iOS, and web, with Windows, macOS, and Linux as potential follow-on targets. These priorities are proposed and need product confirmation.

- [Flutter feasibility assessment](docs/flutter-feasibility.md)
- [First vertical slice and decision gates](docs/first-vertical-slice.md)
- [Gamified next-generation activities](docs/gamified-activities.md)

## Public repository boundaries

Only newly authored implementation, synthetic examples, and approved public assets belong here. Do not copy private application code, proprietary learning content, learner records, recordings, credentials, or internal infrastructure configuration.

Keep API secrets on the server. Client applications, including compiled native apps, cannot keep embedded secrets confidential. Any future backend integration needs a separate security and publication review.

## Development status

No SDK version, package set, application identifier, production API, or deployment pipeline has been selected. There are no app build or test results yet. The next step is a small runnable Flutter proof of concept using synthetic content.
